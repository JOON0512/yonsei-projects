# C++ · 병렬 프로그래밍 실습

본인의 LearnUs 제출 압축파일 5개에서 복원했습니다. 수업 제공 골격·검사 코드와 작성한 구현이 함께 있으며, 과제별 상태를 독립적으로 보존합니다.

| 폴더 | 내용 | 실행 조건 |
|---|---|---|
| class | 클래스·상속과 도형 계산 | C++ 컴파일러, make |
| template | 템플릿 기반 vector | C++ 컴파일러, make |
| thread | 병렬 merge sort | C++ 컴파일러, pthread |
| mpi | 분산 1D/2D DFT | MPI C++ 도구, mpirun |
| gpu | CUDA Mandelbrot 시각화 | NVIDIA CUDA, OpenGL/GLUT, 그래픽 환경 |

각 폴더에서 `make`로 빌드합니다. CPU 실습 검증은 상위 폴더에서 `python3 tests/run.py`로 실행합니다. MPI 입력 파일은 제출본과 함께 보존했고, 재생성할 수 있는 결과 덤프·실행 파일은 제외했습니다.

복원하면서 `thread`의 크기 0 입력이 끝없이 반복되는 문제를 막았습니다. MPI에서는 자기 rank의 수신 버퍼를 자기 전송 버퍼와 겹치게 등록하지 않도록 자기 자신에 대한 송수신을 생략하고, 폭 0을 거부하도록 수정했습니다. 원본 제출 압축파일은 별도로 보존했습니다.

2026-10-25 Ubuntu 24.04, g++ 13/OpenMPI에서 class·template 실행을 ASan/UBSan으로 점검했습니다. 병렬 정렬은 길이 0, 1, 2, 17, 513과 스레드 1, 2, 4, 8 조합을 `std::sort`와 비교했습니다. MPI는 4×4 복소 DFT의 모든 원소를 독립 계산과 비교하여 rank 1, 2, 3, 6에서 통과했습니다. CUDA 코드는 복원했지만 GPU 빌드·실행은 검증하지 않았습니다.

추가로 template의 복사 생성자가 멤버를 초기화하지 않던 오류와 첫 원소 삭제 뒤 begin 이전으로 이동하던 iterator 사용을 고쳤습니다. 빈/비어 있지 않은 vector 복사, 복사 후 독립 수명, 빈 vector 삽입을 ASan/UBSan 검사에 추가했습니다. 범용 표준 컨테이너의 모든 예외 안전성·타입 조건을 만족한다고 검증한 라이브러리는 아닙니다.
